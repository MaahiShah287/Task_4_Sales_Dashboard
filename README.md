 📊 E-Commerce Sales Dashboard | Power BI

📌 Project Overview

This project is an interactive **E-Commerce Sales Dashboard** built using **Microsoft Power BI**. It helps business stakeholders analyze sales performance, monitor key performance indicators (KPIs), and gain valuable insights through interactive visualizations.

The dashboard provides an easy way to track sales, profit, quantity sold, average order value, customer behavior, payment methods, and monthly profit trends.



 🎯 Objective

- Build an interactive dashboard for business stakeholders.
- Analyze sales performance using KPIs.
- Provide interactive filtering using slicers.
- Present meaningful business insights for better decision-making.



🛠️ Tools Used

- Microsoft Power BI Desktop
- Power Query
- DAX (Basic Measures)
- CSV Dataset


 📂 Dataset

The dashboard is created using an **E-Commerce Orders Dataset** containing information such as:

- Order ID
- Order Date
- Customer Name
- State
- City
- Category
- Sub-Category
- Quantity
- Amount
- Profit
- Payment Mode



 📈 Dashboard Features

 Key Performance Indicators (KPIs)

- 💰 Total Sales
- 📦 Total Quantity Sold
- 📈 Total Profit
- 💳 Average Order Value (AOV)

 Interactive Visualizations

- Sales by State
- Quantity by Category (Donut Chart)
- Monthly Profit Analysis
- Profit by Sub-Category
- Sales by Customer
- Quantity by Payment Mode
- Quarter Slicer for Interactive Filtering



 📊 Business Insights

- Maharashtra generated the highest sales.
- COD is the most preferred payment mode.
- Printers contributed the highest profit among sub-categories.
- Monthly profit varies throughout the year.
- Interactive filters allow users to analyze data efficiently.
